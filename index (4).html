EQ-5D-5L — เครื่องคำนวณคะแนน

บันทึก health state profile และคำนวณ Thai EQ-5D-5L index value

1. ข้อมูลผู้ประเมิน (ไม่บังคับ)

EQ VAS เป็นคะแนนการประเมินสุขภาพด้วยตนเอง แยกจาก index value และไม่นำมารวมในสูตร index

2. เลือกระดับปัญหาในแต่ละมิติ

เลือก 1 ระดับต่อมิติ ตามคำตอบของผู้ตอบแบบสอบถามฉบับที่ได้รับอนุญาตให้ใช้

3. ผลการคำนวณ

Health state profile
—
Thai EQ-5D-5L index value
—
EQ VAS (ถ้ากรอก)
—

เลือกคำตอบครบทั้ง 5 มิติก่อน แล้วกด “คำนวณคะแนน”

ข้อควรทราบ: index value ไม่ใช่ร้อยละ และอาจติดลบได้ตาม Thai value set การแปลผลควรดูบริบทและใช้คะแนนที่คำนวณจาก value set เดียวกันในการเปรียบเทียบ

หลักการคิดคะแนน

สร้างรหัสสุขภาพ 5 หลักตามลำดับ Mobility – Self-care – Usual activities – Pain/Discomfort – Anxiety/Depression โดยแต่ละหลักเป็นระดับ 1–5 (1 = ไม่มีปัญหา, 5 = มีปัญหารุนแรงที่สุด) จากนั้นคำนวณด้วย Thai EQ-5D-5L value set:

Index value = 1 − ผลรวมค่าน้ำหนักลดลง (decrements) ของระดับที่เลือกทั้ง 5 มิติ

ระดับ 1 มี decrement เท่ากับ 0 ทุกมิติ ส่วนระดับ 2–5 ใช้ค่าน้ำหนักตามตาราง Thai value set ที่ฝังไว้ในเครื่องคำนวณนี้

เครื่องมือนี้เป็นตัวช่วยคำนวณเพื่อการศึกษา/ตรวจสอบ ไม่ใช่แบบสอบถามฉบับทางการ และไม่ได้จัดเก็บข้อมูลลงฐานข้อมูล กรุณาตรวจสอบสิทธิ์การใช้แบบสอบถาม EQ-5D-5L กับ EuroQol ก่อนนำไปใช้จริงหรือทำวิจัย
