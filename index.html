EQ-5D-5L — เครื่องคำนวณคะแนน

บันทึก health state profile และคำนวณ Thai EQ-5D-5L index value

1. ข้อมูลผู้ประเมิน

50/100
0 — สุขภาพแย่ที่สุด100 — สุขภาพดีที่สุด

EQ VAS รายงานแยกจาก EQ-5D-5L index value และไม่ถูกนำไปรวมในสูตร index

2. เลือกระดับปัญหาในแต่ละมิติ

เลือก 1 ระดับต่อมิติ ตามคำตอบของผู้ตอบแบบสอบถามฉบับที่ได้รับอนุญาตให้ใช้

3. ผลการคำนวณ

Health state profile
—
Thai EQ-5D-5L index value
—
EQ VAS
50/100

เลือกคำตอบครบทั้ง 5 มิติก่อน แล้วกด “คำนวณคะแนน”

ข้อควรทราบ: index value ไม่ใช่ร้อยละ และอาจติดลบได้ตาม value set การแปลผลควรดูบริบทและใช้คะแนนจาก value set เดียวกันในการเปรียบเทียบ

4. รายการผลที่บันทึกไว้ในหน้านี้

กด “บันทึกผลนี้ในรายการ” หลังคำนวณแต่ละราย เพื่อรวมหลายรายการก่อนส่งออก ข้อมูลอยู่ในหน้านี้ชั่วคราวเท่านั้น หากปิดหรือรีเฟรชหน้า รายการที่ยังไม่ส่งออกอาจหายไป

ยังไม่มีรายการที่บันทึก

รหัสวันที่ProfileIndexEQ VASMOSCUAPDAD

หลักการคิดคะแนน

สร้างรหัสสุขภาพ 5 หลักตามลำดับ Mobility – Self-care – Usual activities – Pain/Discomfort – Anxiety/Depression โดยแต่ละหลักเป็นระดับ 1–5 (1 = ไม่มีปัญหา, 5 = มีปัญหารุนแรงที่สุด) จากนั้นคำนวณด้วย Thai EQ-5D-5L value set:

Index value = 1 − ผลรวมค่าน้ำหนักลดลง (decrements) ของระดับที่เลือกทั้ง 5 มิติ

เครื่องมือนี้เป็นตัวช่วยคำนวณเพื่อการศึกษา/ตรวจสอบ ไม่ใช่แบบสอบถามฉบับทางการ กรุณาตรวจสอบค่าน้ำหนัก Thai value set และสิทธิ์การใช้แบบสอบถามกับ EuroQol ก่อนนำไปใช้ในงานวิจัยหรือคลินิก
